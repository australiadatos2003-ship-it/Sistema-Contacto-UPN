
# Sistema de Contacto UPN

## Descripción
Sistema desarrollado para facilitar el registro, búsqueda y gestión de solicitudes académicas de los estudiantes de la Universidad Privada del Norte (UPN).

## Objetivo
Agilizar la gestión de solicitudes académicas y contribuir a reducir los tiempos de espera en la atención a los estudiantes.

## Tecnologías utilizadas
- Lenguaje de programación: Python.
- Entorno de desarrollo: Visual Studio Code.
- Control de versiones: Git.
- Repositorio: GitHub.

## Funcionalidades
- Registro de solicitudes académicas.
- Búsqueda de solicitudes.
- Gestión de información de estudiantes.

## Integrantes
Equipo de desarrollo del proyecto Sistema de Contacto UPN.
